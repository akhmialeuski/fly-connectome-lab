# Third-party software and data

This repository is for source-controlled project materials only. It does **not** bundle MaleCNS, CelebA, LFW, MedMNIST data files, model checkpoints, or generated experiment artifacts.

The table below separates third-party software from third-party datasets so that code licenses are not confused with data licenses or access terms.

## Practical policy for this repository

- Keep third-party datasets outside Git.
- Keep generated traces, checkpoints, caches, and experiment outputs outside Git.
- Keep software-license statements separate from data-license statements.
- Before releasing any trained model, derived cache, embedding store, or demo asset built from third-party data, verify that redistribution is allowed by the relevant upstream terms.
