# Contributing

This repository is an early-stage research project. Please keep contributions small, reproducible, and well documented.

Any future experiment contributed here should document:

- hypothesis;
- source dataset;
- dataset version;
- relevant licenses;
- citations;
- exact experiment configuration;
- random seeds;
- baseline or control;
- evaluation metrics; and
- reproducibility information.

Do not add application code, dependencies, downloaded datasets, model checkpoints, or generated experiment results unless a repository issue explicitly requests them.
