# T29 result: input accuracy recovered, predeclared joint gate failed

The [T29 protocol](protocol.md) was committed at `66c5801` before either model was fitted. It reused the original 20-identity CelebA training split: 14 photographs per identity, deterministic `stable_int(sample_id)` ranks 0–9 for fitting and ranks 10–13 for held-out **training** queries. Both transparent controls used all 16 raster windows and the original alignment/encoder. The two simple diagnostic models used identical 200/80 roles, fold-local scaler/PCA(60), five stratified CV folds, seed 0, fixed C grid, and no fly simulation. No validation, historical test, or reserve photograph was scored.

| Representation | Best C by fit-fold accuracy | Mean CV top-1 | Fit top-1 | Query top-1 | Query top-5 | Query log loss |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| Raster RGB pixels, all windows | 0.1 | 46.0% | 200/200 | **38/80 (47.5%)** | 77.5% | 2.77046 |
| Original sparse encoded current, all windows | 10 | 47.0% | 200/200 | **37/80 (46.25%)** | 80.0% | **4.15056** |

Uniform 20-way choice is 5%, or 4/80 expected correct by chance. The frozen gate required **both** representations to achieve at least 20/80 (25%) and log loss strictly below `ln(20) = 2.99573`. Both accuracy conditions passed. Pixel log loss passed. Encoded-current log loss failed, so the **joint gate did not advance**. This is a valid negative decision under the stated protocol, not a failed solver run. The encoded model selected C=10 from near-flat CV accuracies (46.0%, 46.0%, 46.5%, 47.0% for C 0.01, 0.1, 1, 10) and fit all 200 references exactly. On its 43 incorrect queries, mean negative log probability assigned to the true class was 7.581, versus 4.986 for the pixel model's 42 incorrect queries. The markedly worse current log loss despite similar accuracy is consistent with overconfident mistakes under accuracy-selected regularization; it does **not** by itself prove that C is the sole cause. No query-informed retuning was performed.

The earlier T28 input-control scores of 3/40 for both representations came from a different two-photograph, three-window **raw one-nearest-neighbor** task. T29 shows that the original pixel and encoded-current inputs retain substantial identity information with ten fitting photographs per identity, all windows, and a fitted linear diagnostic. That contrast locates one source of T28's weak controls in its restricted measurement protocol; it does not isolate a causal loss inside MaleCNS. A matched neural study must use the same cohort, windows, readout budget, and appropriate noise controls before making that comparison. The 80 queries remain members of the original training split and provide exploratory evidence only, not new confirmation accuracy.

## Failure, controls, and provenance

Initial attempt A0 (source `309a3b8`) failed **before fitting** because the guard directly compared the JSON list of C values to an equal-valued Pydantic tuple. This implementation type mismatch was corrected in `e69ffe7` by normalizing the tuple for comparison, with a regression test that accepts the real frozen schedule and rejects a changed numeric C. A0's failed manifest/inventory is preserved unchanged in `snapshot/A0`; it has no scientific score. Completed A1 used source `e69ffe7`, took 44.77 seconds inside the attempt, and reached 1,234,239,488 bytes peak RSS, within the 60-minute and 12-GiB limits.

Source and aligned-image hashes, original membership, exact CV folds, encoder/brain-file hashes, feature-array digests, finite arrays, both fitted coefficients, and 560 fit/query probability rows are recorded. No pixels, encoded feature matrices, or downloaded connectome files are archived. [Independent numeric inference replay](provenance/numeric-replay.json) reconstructed all 560 probability vectors from the exported NPZ coefficients using SciPy softmax, reproduced both query accuracies, log losses, and the failed gate, and found maximum absolute probability differences below `1.5e-15`. [Byte-for-byte source-copy verification](provenance/source-copy-verification.json) covers both attempts and all 19 files (56,159,019 bytes).

Next, investigate confidence calibration and the accuracy-only C-selection metric **using fit-fold data**, with a separately frozen protocol. Because T29 query labels have now been inspected, later work must treat these same 80 photographs as development observations, not fresh confirmation. Do not change the T29 gate after the fact or claim a fly-network bottleneck from this input-only study. Publish the new design and any failed attempts in their own issue and dated sibling study.
