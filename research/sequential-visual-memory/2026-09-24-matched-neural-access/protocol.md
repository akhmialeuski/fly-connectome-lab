Owning issue [#62](https://github.com/akhmialeuski/fly-connectome-lab/issues/62). Parent input measurement [T30](../2026-09-24-input-loss-selection/results.md), after the separate T29 negative gate. This protocol and [exact source/analysis schedule](schedule.json) are committed **before** any T31 neural readout fit. They do not change a previously completed fly simulation, source image, connectome weight, or T29/T30 decision.

## Matched data and original neural traces

Use the exact T29 280-photograph original **training** cohort and rank rule: 200 fit references, 80 previously inspected training queries, 20 identities, and the same five fixed 160/40 fit folds. Use all 16 original raster windows, original sparse current, unchanged MaleCNS graph/weights/neuron equations, 20 ms physical step, original 0.05 voltage kick, original ten steps per observation, and the existing descending-neuron spike trace plus voltage. The three source traces, their manifest/features/samples hashes, episode seeds, noise treatments, and archive locations are frozen in `schedule.json`: N0 and N1 use two original episode-noise streams with identical warmed rest; OFF disables episode noise after that rest. These are **persistent sequential episodes**, not independently reset patch presentations. Each source trace includes 280 train and 60 earlier validation episodes; select only the 280 train IDs, and never use validation, historical test, or reserve features/labels/scores for fitting or this decision. No new fly simulation is needed; the exact native float32 traces already exist and are archived under the earlier noise study.

For each condition, concatenate all 16 sequential observations of the original 2,628-wide descending-neuron readout in order to form one 42,048-dimensional float32 feature per photograph. Keep both predeclared blocks (`spike_trace`, `voltage`) and all windows; do not select a population, patch, checkpoint, feature precision, stimulus amplitude, or duration by looking at scores. Verify the source inventories, config, graph and encoder hashes, complete trace shape and finiteness, original training membership, and exact sample order before fitting. The full 60 validation rows can be read as part of immutable source integrity checks, but they must not enter a feature matrix passed to fitting or scoring.

## Fit-only matching and decision

Use the same readout family and capacity as T30 on each neural condition separately: fold-local `StandardScaler -> PCA(60) -> LogisticRegression`, fixed C grid `[0.01, 0.1, 1, 10]`, five exact stratified folds, seed 0, tolerance `1e-6`, at most 50,000 iterations, one BLAS thread. Select C only by minimum pooled 200-row out-of-fold natural-log loss, tie-breaking toward smaller C. Retain every C/fold iteration and score, every OOF probability row, and the selected fitted scaler/PCA/classifier arrays. Convergence warnings are failures, not scientific scores. Do not reuse T30 fitted weights: matching the fitting **protocol** is the control. T30's fixed encoded-current selected-C OOF probability rows are the input reference on exactly the same 200 fit sample IDs and labels.

For N0, N1, and OFF, report OOF top-1/top-5/log loss, the per-image correctness pairing against encoded current, and neural-minus-input accuracy in percentage points. For N0 and N1 separately, resample the 20 original **identity clusters** with replacement exactly 10,000 times using `SeedSequence([0, stable_int('t31-identity-bootstrap')])`; each selected identity contributes all ten fit photos. Report the 2.5/97.5 percentiles with NumPy's linear interpolation, the exact seed, and the complete resample distribution or sufficient numeric counts. The predeclared **sampled-state loss gate** passes only if *both* original-noise streams have neural-minus-current OOF top-1 difference at most -10 percentage points, upper 95% cluster-bootstrap limit below 0, and neural OOF log loss above the encoded-current OOF log loss. OFF is a sensitivity condition and cannot substitute for N0 or N1. Otherwise the matched comparison is inconclusive. This is an exploratory fit-cohort comparison; even a passing gate localizes loss only to the complete input-injection-to-descending-observation/readout pipeline, not specifically to synaptic transmission, noise, temporal filtering, or plasticity.

Fix all three C choices and the OOF gate before refitting on the 200 references and scoring the 80 **already inspected** T29/T30 training queries. Those query scores are descriptive development evidence only. They cannot override the fit-only gate and are not untouched confirmation. This study does not compare persistent with reset memory, so any recognition difference is **not** a sequential-memory benefit.
