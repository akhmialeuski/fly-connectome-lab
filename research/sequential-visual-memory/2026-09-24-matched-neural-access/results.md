# T31 result: large gap at the sampled descending-state readout

The [T31 protocol](protocol.md) and exact source-trace/analysis hashes were pushed at `3c95c3c` before any neural readout fitting. Completed A0 ran from clean source `ca11776`. It reused three previously recorded **native float32 persistent sequential traces** from the unchanged MaleCNS model: N0 and N1 with two original episode-noise seeds, and OFF after the same warmed rest. Each trace records the original 16 raster observations, 1,314 descending neurons' spike trace and voltage (42,048 concatenated features), and 280 original training plus 60 historical validation episodes. Only the exact T29/T30 200 fit and 80 previously inspected training-query IDs were selected; validation, historical test, and reserve data never entered fitting or scoring. The complete 16-window sparse encoded-current input from T30 was the fixed paired OOF reference on the same 200 fit photographs. All representations used the same five folds, fold-local scaler/PCA(60), C grid, convergence budget, and minimum pooled OOF log-loss selection. No fly parameter or source trace was changed.

The predeclared **sampled-state loss gate passed** in both required original-noise streams: each neural score was at least 10 percentage points below its paired encoded-current control, each identity-cluster bootstrap upper limit was below zero, and each neural log loss exceeded the input loss. The bootstrap resampled the 20 original identity clusters 10,000 times using the frozen SeedSequence and retained every draw. N0 and N1 share the same 200 fit photographs and are sensitivity repetitions, not independent data cohorts. With 20 identities, uniform top-1 chance is 5%; N0 is exactly at that reference and N1 is close. OFF does not rescue recognition and has extreme log loss despite slightly higher top-1, so removing episode noise is not a sufficient solution. All 12 fixed C candidates, including worse scores, remain in the archive.

The paired image ledger reveals the contrast directly: N0 and encoded input were both correct on 4/200, input-only correct on 88/200, neural-only correct on 6/200, and both wrong on 102/200. N1's corresponding counts were 6, 86, 5, and 103. This comparison is much stronger than T28's two-photograph, three-window raw-distance check because cohort, all windows, fitting folds, and readout family/capacity match. It supports a large loss somewhere along the complete **encoded-current injection → fixed fly dynamics → sampled descending state → linear readout** measurement pathway. It does **not** distinguish inadequate delivery to particular neurons from temporal filtering, noise, operating point, omitted populations, or synaptic/neuronal dynamics. It is not proof that the fly connectome in general cannot encode identities.

After all three neural C choices and the OOF gate were fixed, the previously inspected 80 training queries were scored descriptively: N0 8/80 (10.0%, log loss 4.43185), N1 3/80 (3.75%, loss 3.93430), OFF 6/80 (7.5%, loss 15.57273), versus the T30 encoded-current input's 36/80 (45.0%, loss 2.29866). These are **not** new confirmation scores and cannot change the OOF gate. The neural traces carry sequential state across 16 patches, but this study does not compare matched persistent/reset conditions; no memory benefit is established.

The next study should probe **where** the signal disappears under a frozen cohort: compare predeclared early visual-projection, intermediate, and descending populations at matched physical times and readout budgets, alongside paired input/blank and noise controls. Only after that localization should a specific signal-transfer equation or constrained-plasticity intervention be proposed. A later untouched, frozen recognition evaluation and a separate persistent/reset intervention are required for any final accuracy or sequential-memory conclusion.
