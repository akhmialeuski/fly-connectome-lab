# T28: training-only identity access in fixed fly responses

Owning issue: [#56](https://github.com/akhmialeuski/fly-connectome-lab/issues/56). Parent stage-0 measurement: [T27](../2026-09-24-temporal-population/results.md). This protocol and its exact cohort are committed **before** any T28 response simulation. The question is whether image-dependent state in the unchanged MaleCNS model also preserves information shared by two photographs of the same identity. It is not a sequential-memory or untouched-confirmation experiment.

## Frozen input and observation design

Use the original `configs/celeba-smoke.yaml` configuration (SHA-256 of its effective JSON `9406ee5b0f5b2ba794b71bad4def5d906248af35165f49a8fceb7f0c96fe82b3`), the archived #50 training membership (canonical membership SHA-256 `5af10356b3ff565bf515144983758763fb8b346737520c50647885cdf88a92d8`), and the exact T27 aligned-image preprocessing key. [cohort.json](cohort.json) freezes two photographs per identity for labels 0 through 19, selected by ascending `(stable_int(sample_id), sample_id)` from the original **training** membership. It records each source JPEG and aligned RGB-array hash. It includes the eight T27 pilot photographs and thus is an expansion, not independent confirmation. Do not inspect validation, historical test, or reserved images or their scores during this study.

Reuse the four T27 1,314-neuron masks from [population-masks.json](../2026-09-24-temporal-population/population-masks.json), whose exact file SHA-256 is frozen in `cohort.json`. Verify graph source and selected bodyIds at runtime. Keep all three raster windows 0, 7, and 15. Use the same warmed rest state, the existing sparse pixel encoder and its 0.05 float32 voltage kick for ten 20 ms steps, and ten further steps with no encoder current. Record global checkpoints `0, 1, 2, 5, 10, 11, 12, 15, 20`. A window is always replayed in isolation from the warmed state; there is no carryover from earlier windows.

The fixed execution order is N0 (original episode noise, common stream seed 0), N1 (original episode noise, common stream seed 1), and OFF (episode noise disabled). For N0 and N1, the `EpisodeBrain.begin` noise identifier is `identity-access|window=<window>|stream=<N0|N1>` for **every** image in that window/condition. This common-random-number intervention makes image comparisons within a window conditional on identical noise draws, as in the earlier signal-stability diagnostic. It does not change the fly step equation or the image's recorded sample ID. Each condition also records one zero-current blank per window with the same rest and noise identifier. OFF records three explicit zero-noise blanks. All 40 × 3 × 3 driven presentations plus nine blanks are saved; no arbitrary subset can be dropped after viewing results.

Every attempt saves the exact ordered sample IDs and labels, window, condition, source hashes, physical timing, per-step episode-noise/spike/active counts, all selected-neuron float32 voltages and int32 cumulative spikes, and the existing descending-neuron exponential spike trace. Recompute rather than archive source photographs or transformed images. Stop the campaign if total wall time exceeds 60 minutes or peak RSS exceeds 12 GiB, and preserve the failed/stopped attempt in the ledger. The dataset and graph files remain outside Git.

## Frozen analysis

For each condition, sample, window, and checkpoint, compute the voltage vector `stimulus - time-matched blank` for each fixed mask. Use float64 accumulation for distances over saved float32 values. At stimulus endpoint step 10, concatenate all four mask vectors and all three windows in the fixed order `visual_projection`, `ol_intrinsic`, `cb_intrinsic`, `descending_neuron` and windows `0, 7, 15`. This 15,768-dimensional vector is the single **primary** neural feature. It has no fitted scaler, PCA, selected mask, or selected window. Analyze N0 and N1 separately; OFF is a sensitivity condition. Step-20 recovery and individual masks/windows are diagnostic maps only and cannot override the primary decision.

There are exactly 20 same-identity image pairs and 760 different-identity image pairs among 40 photographs. Report the means, medians, full pair records, and the ratio of mean within-identity to mean between-identity squared Euclidean distances for every fixed analysis view. Also compare each photograph's N0 and N1 response under the two independent common-noise streams. A distance ratio alone is not an accuracy score.

The primary identity diagnostic is one-nearest-neighbor matching with squared Euclidean distance: use the first ranked photograph of each identity as the 20 reference vectors and the second as the 20 held-out **training** queries, then swap. Exclude self matches, break equal-distance ties by the lowest identity label, and store every query, predicted identity, distance, and correctness. Thus each condition has 40 fixed queries and a 5% uniform-choice reference. Apply the identical concatenated-window two-direction protocol to the deterministic raster pixels and sparse encoded currents as input controls, without a learned transform. These controls are diagnostic and do not replace the fly recognizer.

For the primary neural score, generate exactly 10,000 seeded random permutations with `numpy.random.SeedSequence([0, stable_int('t28-primary-null')])`. Each permutation reassigns the 20 held-out query labels relative to the fixed reference labels and is applied to both swap directions. Keep the full null score histogram and compute the upper-tail plus-one p-value `(1 + count(null_score >= observed_score)) / 10001`. The **stage gate passes only if** N0 and N1 each have `p < 0.05` and mean within/between squared-distance ratio `< 1`. This is a training-only exploratory gate, not proof of generalization; no favorable secondary population/window/checkpoint score may substitute for it. If it fails, report the input-control and OFF results, cross-seed stability, and measured failure pattern before proposing a later dynamics or constrained-plasticity intervention. Do not alter the current, duration, masks, analysis rule, or null after viewing responses.
