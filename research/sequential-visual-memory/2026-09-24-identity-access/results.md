# T28 result: limited training-only identity access

The preregistered [T28 protocol](protocol.md) completed on 2026-09-24. It used the unchanged MaleCNS graph, neuron equations, sparse pixel encoder, original 0.05 voltage kick for ten 20 ms steps, and four fixed 1,314-cell masks from T27. Exactly two training photographs from each of the original 20 identities were viewed at raster windows 0, 7, and 15. Every image/window presentation started independently from the same warmed state; this study did **not** run a sequential-memory episode. The N0 and N1 conditions used distinct image-independent common-noise streams, each matched exactly to its own zero-current blank by per-step SHA-256 of the actual noisy neuron indices. OFF disabled episode noise and used its own blank. All three source inventories, external image hashes, input-current hashes, rest-state controls, finite arrays, and noise controls passed before analysis.

The single primary neural feature was fixed in advance: concatenate the paired stimulus-minus-blank voltage of all four masks and all three windows at step 10. This produces 15,768 float64 analysis coordinates per image from archived float32 states. With the first photograph of each identity as reference and the second as a held-out **training** query, then the directions swapped, the fixed one-nearest-neighbor diagnostic made 40 queries per condition. The uniform-choice reference is 5% (2/40). The label-permutation test used the frozen 10,000 draws and the plus-one upper-tail p-value.

| Condition | Correct / 40 | Accuracy | Permutation p | Mean within / between squared-distance ratio |
| --- | ---: | ---: | ---: | ---: |
| N0, original noise stream 0 | 5 | 12.5% | 0.0468 | 0.929 |
| N1, original noise stream 1 | 4 | 10.0% | 0.1315 | 0.949 |
| OFF, episode noise disabled | 3 | 7.5% | 0.3290 | 0.927 |
| Raster-pixel input control | 3 | 7.5% | Not a primary permutation test | 0.832 |
| Sparse encoded-current input control | 3 | 7.5% | Not a primary permutation test | 0.848 |

The **predeclared stage gate failed**: both original-noise streams needed `p < 0.05` and within/between ratio `< 1`. N0 met those numerical conditions but N1 did not. OFF did not improve matching under this feature and tiny reference set. A same photograph's N0-versus-N1 primary squared distance averaged 474.84, compared with matched-noise between-identity means of 278.64 in N0 and 276.77 in N1. This describes substantial noise sensitivity, not a causal recognition benefit from changing noise; the earlier controlled recognition study #50 already found no advancement from simply removing episode noise.

The input controls are decisive for interpretation. On the **same 2-shot, three-window, raw 1-NN protocol**, pixels and encoded currents each matched only 3/40 queries, despite within-identity distances being smaller on average. Thus this T28 diagnostic does not isolate a fly-network bottleneck. Its weak 1-NN performance may reflect too few reference photographs, the selected three windows, identity variation, and the metric itself. It does not contradict the earlier 14-training-photo, all-window, fitted input controls that achieved substantially higher exploratory validation accuracy; those used a different training regime and readout. The 20 within-identity and 760 between-identity pairs are dependent descriptive comparisons, not independent biological replicates. No validation, historical test, or reserved photograph was used for this stage decision.

The next defensible step is a separately frozen training-only diagnostic with a stronger input-control baseline and more original training photographs before testing new fly dynamics or constrained plasticity. Any favorable population/window detail in the 72 secondary maps cannot override this negative primary gate. The full [machine-readable report](snapshot/analysis/report.json), 60,060 pair rows, 3,080 query rows, and 40 cross-seed rows retain all positive and negative evidence. [Independent replay](provenance/analysis-replay.json) used SciPy distances to reproduce every primary and input-control pair/query decision, all three null histograms, and the gate from the archived numeric responses and external training images. Maximum absolute primary pair-distance difference was below `2.6e-11`.
